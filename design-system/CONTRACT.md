# Panel interface contract

The current reference is the supplied Skymetrics dashboard image. Apply its calm visual language to infrastructure operations: a neutral outer frame, white slim navigation, pale gray canvas, white rounded cards, large dark headings, fine outline icons and mint status accents. The temporary product label is Panel. No inherited product assets are used.

Use locally packaged Inter and system monospace for identifiers and operation output. Cards have 22-24px radii, 12-16px gaps and low-contrast dotted separators. Main actions are dark rounded pills. Status badges use mint, pale amber and pale red without relying only on color.

The overview has five real summaries: projects, services, active operations, completed operations and Docker connectivity. The wide content region contains projects and recent actions. Its narrower aside shows actual engine capacity and actual operation counts. No invented graphs, sample workloads, conversion data or fabricated metrics appear.

The UI/UX skill search returned an operations-oriented pattern, but its glass treatment conflicts with the supplied reference. Apply the verified guidance for truthful live state, accessible controls and reduced motion while the user's image determines the visual layout.

Saved configuration and running deployment state are separate. A save never announces a successful deploy. Action logs show actual worker events and poll while pending. Offline runtime states show unavailable data and the returned connection error.

Forms have visible labels, native validation, inline request errors and submission feedback. Native dialogs contain focus. Narrow screens collapse navigation labels while accessible link names remain available. A skip link leads to the main content.
